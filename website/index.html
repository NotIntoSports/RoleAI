RoleAI

实时互动的数字人。

角色以虚拟形象出镜，你说话，对方看着你回答。可用于面试、会议和讲解。 Windows 桌面版接通真实实时通话；在线演示里数字人会出镜说话。

在线体验演示版 下载 Windows 版 阅读文档

当前版本是 Windows x64 内部试用版。使用前须告知对方数字人参与和记录方式，并由人工复核； 不得用于隐蔽冒充或未经复核的自动决策。在线演示里数字人会出镜说话，字幕跟着走；真实实时通话在桌面版中进行。

三个核心能力

围绕“实时交流”设计的完整闭环，从对话到记录一目了然。

  • 实时语音对话

    说话字幕逐字上屏，AI 回答流式显示；播放中可以随时打断，暂停、接管、纠正都有对应控制。

  • 角色与资料驱动

    内置严苛面试官、表达教练、会议助手、直播讲解员、辩论陪练、英语口语陪练等 8 个角色；导入资料后回答可以检索并标注引用。

  • 本机优先

    角色配置、资料和会话记录保存在本机，密钥存入 Windows 凭据管理器；记录支持导出 Markdown。
